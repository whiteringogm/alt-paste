# Alt Paste

ユーザーとAIの発言を1つずつ貼り付けると、発言者を交互に付けてまとめてコピーできるPWA。外部ライブラリ、CDN、外部APIは不要。

## 使い方

1. 最初に貼る側を選ぶ。
2. 1発言をコピーし、「コピーした発言を貼る」を押す。入力欄への通常のペーストでも自動追加される。
3. 次の発言をコピーして同じ操作を繰り返す。1回の貼り付けが1発言となり、次の発言者が自動で切り替わる。
4. 「まとめてコピー」で発言者付きのログをコピーする。

ボタンでのクリップボード読み取りが使えない場合は、入力欄を長押ししてペースト、または Ctrl / Cmd + V。すでに手入力した文章がある場合は追記になり、「入力分を追加」で確定する。複数発言をまとめて貼り付けても自動分割はしない。

設定で両者の名前と見出し形式を変更できる。発言単位の編集・削除、次の側の手動切替、直前の操作の取り消し（同じ起動中で最大20操作）に対応。全消去も直後なら取り消せる。

ログ、入力途中の文章、設定はブラウザのlocalStorageに自動保存。サーバーへ送信しない。端末・ブラウザ間の同期はない。ブラウザのデータを消すとログも消えるので、必要なログはコピーして保管する。

## GitHub Pages

リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch**、ブランチ **main**、フォルダ **/(root)** を選び保存する。

HTTPSの公開ページを一度開いたあと、オフラインでも利用できる。iPhoneはSafariの共有メニューから「ホーム画面に追加」。インストールとクリップボードの機能はブラウザごとの差がある。

## 開発

ビルド不要。ルートディレクトリを静的HTTPサーバーで配信する。`npm test` で発言の交互割り当て、本文保持、出力形式、保存データ検証を確認できる。更新時は `sw.js` のキャッシュ名と画面のバージョン表記を更新する。
